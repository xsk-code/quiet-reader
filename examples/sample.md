# 一次安静的阅读

这是一篇由拾页项目编写的示例，用于检查导入、标题、目录、表格、代码和阅读进度。它不是抓取自第三方网站的文章，也不是模型生成能力的实测结果。

## 从一段文字开始

把本文粘贴到输入框，或通过附件按钮打开这个 Markdown 文件。配置好正文接入后，点击“开始阅读”，就能验证完整流程。

> 先让第一篇文章顺利读完，再配置可选的图片服务。

## 一个小小的检查清单

- 译文、原文和对照模式可切换；导入栏「译为」可选择目标语言。
- 标题可以出现在目录里。
- 阅读位置会保存，文章也会保存在本机。

| 功能 | 验证方式 |
| --- | --- |
| 正文翻译 | 完成后显示译文 |
| 阅读进度 | 滚动后重新打开 |
| Markdown 导出 | 下载并检查标题和列表 |

```js
const message = '代码内容应保持原样';
console.log(message);
```

## 继续阅读

默认不会把滚动到末尾自动算成读完。确认读完后，点击正文底部“标记为已读完”。
